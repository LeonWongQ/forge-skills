# Test Report Checklist

## 1. Basic Information
- [ ] Project/product information is provided
- [ ] Module/feature is clearly identified
- [ ] Version/build is recorded
- [ ] Test type is specified
- [ ] Test environment and test period are included
- [ ] Tester(s) are identified

## 2. Objective and Scope
- [ ] Test objective is clearly stated
- [ ] Quality goals are described
- [ ] Scope in and scope out are defined
- [ ] Key risks to validate are listed

## 3. Test Basis and Environment
- [ ] Requirements/specifications are referenced
- [ ] Related tickets/changes are referenced
- [ ] Test cases or checklist are referenced
- [ ] Test environment is described
- [ ] Dependencies and test data are identified
- [ ] Environment constraints are documented

## 4. Execution and Coverage
- [ ] Planned and executed test counts are included
- [ ] Pass/fail/blocked/not-run counts are included
- [ ] Pass rate is calculated
- [ ] Coverage summary is provided
- [ ] Main/alternative/exception/boundary coverage is addressed

## 5. Defects and Risks
- [ ] Major defects are summarized
- [ ] Defect severity/priority/status are clear
- [ ] Known issues are documented
- [ ] Untested areas are documented
- [ ] Limitations and residual risks are documented

## 6. Conclusion
- [ ] Final conclusion is explicit: PASS / CONDITIONAL PASS / FAIL
- [ ] Recommendation is actionable
- [ ] Follow-up actions are listed
- [ ] Sign-off information is complete
