# Version

## Current Version

`v1.2.1`

---

## Release Meaning

This version closes the Operational Validation, Compatibility, and Routing Calibration milestone.

At `v1.2.1`, Forge adds reusable operational capabilities on top of the governed architecture:

- template-bound structured JSON output validation
- fixture-backed API/event contract compatibility validation
- observability/reliability and release-readiness guidance
- a non-mutating local quality gate
- deterministic cross-registry semantic validation
- a categorized route/recommend regression corpus with calibrated confidence diagnostics

The repository is a structured, governable, machine-readable modular operating model for AI-assisted engineering work—not merely a prompt collection.

---

## Versioning Interpretation

This repository uses a lightweight semantic interpretation:

- **MAJOR**: architectural or compatibility-breaking change
- **MINOR**: capability expansion or new reusable subsystem
- **PATCH**: clarification, refinement, or non-breaking improvement

Examples:

- new domain module -> MINOR
- new pack -> MINOR
- module rename affecting ids or paths -> MAJOR
- clearer wording in an existing file -> PATCH

---

## Stability Statement

At `v1.2.1`, the architecture and its deterministic local validation tooling should be considered:

- conceptually stable
- structurally usable
- suitable for iterative adoption
- ready for operational validation and compatibility assessment

This version does **not** claim:

- full runtime implementation
- automatic registry generation
- active CI for the junction-deployed source model
- package publication or release automation
- end-to-end LLM structured-output execution

Those remain future operational enhancements, not blockers for the local release baseline.
