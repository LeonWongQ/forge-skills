全局设置

三个宿主的 Forge Hook 可同时启用。开启只安装或修复对应宿主；关闭会在确认后仅卸载该宿主，各项目仍通过 Skill 开关独立决定是否采集。

信任提示如尚未信任 Codex Hook，请在 Codex Desktop 中确认

应用 Codex Hook 后，打开 Codex Desktop → Settings → Hooks，找到用户 Hook，检查命令并点击 Trust / 信任，然后新建 Codex 会话以重新加载 Hook 配置。

“已安装”只表示配置已写入，不代表 Codex 已信任。修改 Hook 后需重新信任；如果没有信任入口，请检查默认用户配置文件： %USERPROFILE%\.codex\hooks.json 如设置了 CODEX_HOME，请检查该目录下的 hooks.json。
